모덕초 오늘의 교육활동 - 휴대폰(안드로이드)용
===========================================

원본 PC 앱(modeok_app.py 등)은 전혀 수정하지 않았습니다.
같은 구글 시트를 읽기만 하는 별도 웹앱이며, 크롬에서 "홈 화면에 추가"하면 앱처럼 쓸 수 있습니다.

■ 폴더 구성
  index.html            앱 본체 (화면·기능 전부)
  manifest.webmanifest  홈 화면 앱 정보(이름·아이콘)
  sw.js                 오프라인에서도 앱이 열리게 해주는 파일
  icon-192.png / icon-512.png  앱 아이콘 (logo.jpg로 만듦)


■ 1단계. 구글 시트에 '복무' 열 추가 (한 번만)
  - 구글 시트 '일정' 탭의 맨 오른쪽 빈 열 1행에  복무  라고 적습니다.
    (지금 열: 날짜 | 업무전달 | 접수대기문건 | 출장 | 한마디  →  뒤에 '복무' 추가)
  - 앱스 스크립트는 고칠 필요 없습니다. 이미 열 이름을 보고 해당 칸에 기록합니다.
  - PC 앱은 '복무' 열을 읽지 않으므로 PC 화면은 그대로입니다.
  - 열이 없으면 휴대폰 앱이 업로드를 막습니다(엉뚱한 칸에 들어가는 것 방지).


■ 2단계. 인터넷에 올리기 (휴대폰에서 열려면 https 주소가 필요)
  가장 쉬운 방법: GitHub Pages (무료)
   1) github.com 에서 새 저장소 만들기 (예: modeok-mobile)
   2) 이 폴더의 파일 5개를 그대로 업로드
   3) 저장소 Settings → Pages → Branch: main / (root) → Save
   4) 1~2분 뒤 https://계정이름.github.io/modeok-mobile/ 주소가 생깁니다.
  ※ 이 폴더의 파일에는 시트 주소·토큰이 전혀 들어 있지 않습니다.
     공개 저장소에 올려도 개인정보가 드러나지 않습니다.


■ 3단계. 휴대폰에 설치
  - 상위 폴더의 '모바일_설정링크.html'을 PC에서 열면 설정 링크와 QR코드가 나옵니다.
    (이 파일은 깃허브에 올리지 마세요. 교직원에게만 메신저/QR로 전달)
  - 휴대폰에서 설정 링크를 크롬으로 열거나 QR을 찍으면 자동 설정됩니다.
    설정 값은 그 휴대폰에만 저장되고, 주소창에서도 바로 지워집니다.
  - 그다음 오른쪽 위 ⋮ → "홈 화면에 추가"(또는 "앱 설치")
  - 홈 화면 아이콘으로 실행하면 주소창 없이 앱처럼 열립니다.


■ 화면 기능
  - 업무전달(체크 가능, 휴대폰에 기억) / 복무 / 접수대기 / 오늘의 한마디 / 안전지도
  - 복무: 출장·연가·병가(병조퇴 포함)·조퇴·외출·지참·육아·모성·특별휴가·기타로 묶어 표시
          같은 시간·장소에 함께 가는 사람은 한 줄로 묶음
          기존 PC 앱이 '출장' 칸에 올린 자료도 같이 보여줌 (겹치면 한 번만)
  - ◀ ▶ 버튼 또는 좌우로 밀어서 날짜 이동, 날짜 글자를 누르면 달력
  - '오늘 / 다음 수업일' 전환
  - 앱을 다시 열 때 10분 이상 지났으면 자동 새로고침, 인터넷이 없으면 마지막 자료 표시


■ 관리자 기능 (오른쪽 위 ⋮ 메뉴)
  - 나이스 복무 엑셀 업로드
      나이스 › 부서일일근무상황목록 엑셀(.xlsx)을 선택하면
      출장뿐 아니라 '모든 복무'를 미리보기로 보여주고 시트 '복무' 칸에 올립니다.
      · 여러 날짜 복무(예: 3일 연가)는 날짜마다 나눠서 올림 (주말 제외)
      · '(일반복)' 반복 복무는 기간 안의 매일로 올림
      · 기간 칸이 빈 항목(예: 병가)은 날짜를 직접 고를 수 있음
      · 반려·취소된 건은 제외
      PC에서도 크롬으로 이 주소를 열어 똑같이 업로드할 수 있습니다.
  - 업무전달 추가
  - 처음 쓸 때 '관리자 토큰' 입력: config_local.py 의 API_TOKEN 값.
    한 번 넣으면 그 휴대폰에만 저장됩니다.


■ 참고
  - 날씨: 시트의 앱스 스크립트(action=weather)에서 가져옵니다.
    현재 그 값이 '조회 실패'라 휴대폰에서는 날씨 줄이 숨겨져 있습니다.
    (PC 앱은 기상청을 직접 부르기 때문에 PC에서는 보입니다.
     앱스 스크립트의 WEATHER_API_KEY 를 넣고 setupTrigger 를 한 번 실행하면 휴대폰에도 나옵니다.)
